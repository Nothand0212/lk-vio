# Triage labels

工程技能使用五个规范 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，应使用本表对应的实际标签字符串。

如果仓库以后改变标签词汇，请修改右侧“本仓库标签”列。
